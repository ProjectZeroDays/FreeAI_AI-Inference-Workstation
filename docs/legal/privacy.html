Privacy Policy

Last updated: January 2026

FreeAI is a self-hosted AI inference workstation. This privacy policy explains how we handle data when you use our documentation, website, and community resources.

Data We Collect

  • Usage Analytics: Anonymous page views and feature usage to improve documentation
  • GitHub Data: Public repository interactions (stars, forks, issues)
  • Contact Information: Email and details you voluntarily provide via contact forms

Self-Hosted Nature

FreeAI is designed to be fully self-hosted. All AI model inference, agent execution, and data processing happens on YOUR infrastructure. We do not have access to your:

  • AI models or model weights
  • Code repositories or source code
  • API keys or credentials
  • Prompt data or conversation history
  • System logs or telemetry (unless you configure it)

Cookies & Tracking

Our documentation site uses minimal cookies for theme preference (dark/light mode) and language selection. No third-party analytics or tracking pixels are employed.

Data Sharing

We do not sell, rent, or share your personal data. Any community contributions (GitHub issues, discussions) are public by design.

Your Rights

  • Request deletion of any personal data we hold
  • Opt out of anonymous analytics
  • Access our complete source code (MIT licensed)

Contact

For privacy inquiries, email privacy@projectzerodays.github.io or open a GitHub issue.
