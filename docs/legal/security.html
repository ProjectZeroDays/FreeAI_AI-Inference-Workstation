🛡️ Security-First Design

Security

FreeAI is built with security as a core principle, not an afterthought.

Built-in Security Features

  • Aikido Integration: Real-time vulnerability scanning and auto-patching
  • API Key Rotation: Up to 10 keys per provider with automatic failover
  • RBAC Controls: Role-based access control for all operations
  • Network Isolation: Optional Tor/DNSCrypt/VPN integration
  • Self-Hosted: Your data never leaves your infrastructure

Security Skills

FreeAI includes 33 expert security skills across three teams:

  • Red Team (14): APT hunting, exploit research, social engineering, LotL techniques
  • Blue Team (12): Hardening, compliance (NIST/FedRAMP/DOD), SIEM, incident response
  • Purple Team (7): Red↔blue orchestration, control validation, remediation

Vulnerability Management

Automated scanning via Semgrep, Bandit, Safety, and Trivy. Critical and high vulnerabilities trigger auto-patch workflows with human approval gates.

Report a Vulnerability

If you discover a security issue, please report it responsibly via GitHub Security Advisories.
