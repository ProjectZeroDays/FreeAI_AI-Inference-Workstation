Campaign Framework

A/B testing and multi-variant campaign framework for authorized red team security assessments.

⚠️ Authorized Use Only

This framework is designed for authorized red team testing against your own infrastructure. All campaigns require written ROE (Rules of Engagement) and proper authorization before execution.

Campaign Types

📧

Phishing Simulation

Test email security awareness with A/B tested templates. Track open rates, click rates, and credential submission.

💾

USB Drop Test

Physical security assessment using labeled USB drives in strategic locations.

📶

Rogue Wi-Fi AP

Network security test using rogue access points to evaluate device connection behavior.

📞

Vishing (Voice)

Social engineering via phone calls with tracked information disclosure rates.

Quick Start

# Generate an A/B test campaign
python scripts/campaign_manager.py --command generate --type ab --variants 2 --budget 1000 --audience 500

# View budget allocation stats
python scripts/campaign_manager.py --command allocate --variants 3 --budget 1000

# Analyze segment distribution
python scripts/campaign_manager.py --command analyze --budget 5000

Statistical Analysis

Built-in statistical testing with chi-square, t-test, and UCB1 multi-armed bandit for dynamic budget allocation. Minimum sample size calculated automatically based on expected conversion rates and confidence levels.

📊 Sample Size Calculator

Auto-calculates minimum sample for 95% confidence and 5% margin of error

🎯 Dynamic Budgeting

UCB1 algorithm reallocates budget to best-performing variants in real-time
