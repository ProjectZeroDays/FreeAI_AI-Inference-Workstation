The Product Suite

FreeAI unifies local LLM serving, autonomous SDLC agents, workflow automation, security tooling, and a full desktop environment — one self-hosted stack.

Core Components

What's Inside

Every subsystem is independently deployable yet fully integrated into a single operational platform.

⚙

Model Router

Classifies prompts, routes to best backend, automatic fallback chains, LRU caching, and degenerate-output detection. Runs on port 8010.

💬

Autonomous Agents

22+ agents across 7 SDLC phases: plan, code, verify, fix, review, document, package. Runs real compilers inside sandboxes.

🚀

Workflow Engine

Visual pipeline builder with parallel/sequential steps, validation, audit logs, and template library. Port 8040.

🔌

GPU Inference

llama.cpp (:9001), vLLM (:9002), FreeToken MoE (:9100). GPU warmup, eco/balanced/perf tuning modes.

📊

Dashboard

19-page dashboard with GPU telemetry, alert system, model shelf, workflow designer, SDLC run viewer. Port 8030.

💻

Desktop Environment

Full XFCE desktop accessible via VNC/noVNC on port 6080. VS Code, terminal, file manager pre-installed.

Deployment

Five Paths to Production

Choose the deployment model that matches your infrastructure.

🗃

Bare Metal

Ubuntu + NVIDIA drivers. Best GPU performance. Auto-driver detection, CUDA toolkit integration.

curl -fsSL install-stack.sh | bash
📧

Docker Compose

Split or all-in-one profiles. Runs on any host with NVIDIA Container Toolkit.

docker compose --profile allinone up -d
⚓

Kubernetes

Auto-scaling, service mesh, horizontal pod autoscaling for production fleets.

kubectl apply -f k8s/manifests/
☁

Cloud GPU

RunPod, Vast.ai, Lambda Labs, Hetzner. One-click deployment scripts included.

bash deploy/runpod.sh
💪

Live ISO

Bootable USB with Ubuntu/Kodachi/Kali/NixOS variants. Install or try without touching disk.

dd if=FreeAI.iso of=/dev/sdX bs=4M
🔌

MOCK Mode

No GPU? Set MOCK_LLM=1 and run the full stack on CPU for development and testing.

MOCK_LLM=1 python3 router/router.py
Security by Default

Built-In Protection

Security is not an afterthought — it's baked into every layer.

🔒

LAN-Only by Default

All model servers bind to 127.0.0.1. UFW firewall exposes only SSH and dashboard ports.

🛡

Sandboxed Agents

Every agent runs in an isolated workspace with file path restrictions, size limits, and command blocking.

🔓

HITL Approval

Human-in-the-loop gates for 6 danger categories — exploit, persistence, credential dump, and more.

⚡

Circuit Breakers

Sliding-window failure detection on router backends. Automatic fallback when confidence drops below threshold.

🔗

SOPS Encryption

All secrets encrypted with age key. Decryption on-demand at runtime — never stored in plaintext.

📌

Compliance Ready

Self-hosting ensures ISO 27001, DOD IL4, FedRAMP, NIST 800-53, CMMC Level 2 & 3 compliance posture.
