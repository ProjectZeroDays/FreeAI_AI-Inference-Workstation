Deploy

Choose your path.

Local, Docker, or cloud — same stack, different runtime.

🐧
Bare Metal

Auto-detects GPU (4090/Z790), installs drivers, CUDA, Docker, and the full stack. Production-ready systemd service.

install.sh 
git clone https://github.com/ProjectZeroDays/FreeAI_AI_Inference_Workstation.git
cd FreeAI_AI_Inference_Workstation
sudo ./hardware/install-stack.sh
bash models/auto-download-models.sh

Dashboard: localhost:8030 · Agent API: localhost:8050

🐳
Docker Compose

Any host with NVIDIA Docker. Split or all-in-one profiles. Zero host dependency management.

docker-compose.yml 
git clone https://github.com/ProjectZeroDays/FreeAI_AI_Inference_Workstation.git
cd FreeAI_AI_Inference_Workstation
docker compose --profile allinone up -d
# Open http://localhost:8030

Profiles: allinone, gpu, cpu, agents

sudo apt-get install -y xorriso isolinux

Platform Support

Works everywhere you do.

Linux, macOS, and Windows — each with its recommended deployment path.

🐧

Linux

Native support. Ubuntu, Debian, Kali, Kodachi, NixOS. GPU acceleration via CUDA / ROCm.

  • Clone repo
  • Run sudo ./hardware/install-stack.sh
  • Auto-detects GPU, installs drivers
  • Dashboard at :8030
🍎

macOS

Via Docker Desktop or Colima. CPU mode natively; GPU offload to Linux hosts or cloud GPUs.

  • Install Docker Desktop
  • Clone repo
  • docker compose --profile allinone up -d
  • Dashboard at :8030
🪟

Windows 10/11

via WSL2 + Docker Desktop, or native Docker with NVIDIA drivers. Full GPU passthrough in WSL2.

  • Enable WSL2, install Ubuntu
  • Install Docker in WSL2
  • Clone repo inside Ubuntu
  • docker compose --profile allinone up -d

FAQ

Frequently asked questions

Do I need a GPU?

No — use MOCK_LLM=1 for CPU-only mode, or connect to hosted APIs (OpenAI, Anthropic, etc.) via the provider system.

How many providers are supported?

22+ hosted APIs including OpenAI, Anthropic, Gemini, Groq, Mistral, DeepSeek, and more via the provider adapter system.

Can I use this for production?

Yes — FreeAI is designed for production with auth, rate limiting, health checks, and auto-restart policies.

Is it open source?

Yes — MIT licensed. Full source at GitHub.

How do I add custom skills?

Use the Skills API or add SKILL.md files to the skills/ directory. See the docs for details.

Can I connect my own models?

Yes — any OpenAI-compatible endpoint works. Configure in config/providers.json or via the dashboard.
