Bare Metal

git clone https://github.com/ProjectZeroDays/FreeAI_AI-Inference-Workstation.git
cd FreeAI_AI-Inference-Workstation
sudo ./hardware/install-stack.sh
bash models/auto-download-models.sh

git clone https://github.com/ProjectZeroDays/FreeAI_AI-Inference-Workstation.git

FAQ

Frequently asked questions

Do I need a GPU?

No — use MOCK_LLM=1 for CPU-only mode, or connect to hosted APIs (OpenAI, Anthropic, etc.) via the provider system.

How many providers are supported?

22+ hosted APIs including OpenAI, Anthropic, Gemini, Groq, Mistral, DeepSeek, and more via the provider adapter system.

Can I use this for production?

Yes — FreeAI is designed for production with auth, rate limiting, health checks, and auto-restart policies.

Is it open source?

Yes — MIT licensed. Full source at GitHub.

How do I add custom skills?

Use the Skills API or add SKILL.md files to the skills/ directory. See the docs for details.

Can I connect my own models?

Yes — any OpenAI-compatible endpoint works. Configure in config/providers.json or via the dashboard.
