Build & Flash

Create Your USB

Download the ISO from GitHub Releases and flash to USB with any standard tool.

# Download the latest release
curl -LO https://github.com/ProjectZeroDays/FreeAI_AI_Inference_Workstation/releases/latest/download/FreeAI.iso

# Flash to USB (replace sdX with your device)
sudo dd if=FreeAI.iso of=/dev/sdX bs=4M status=progress conv=fsync

# Or use BalenaEtcher / Rufus for GUI flashing
