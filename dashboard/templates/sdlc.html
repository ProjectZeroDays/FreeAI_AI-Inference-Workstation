SDLC & Custom Pipelines

Autonomous agents turn specs into shipped projects — or build your own pipeline

The 7-Phase SDLC Lifecycle

FreeAI's autonomous agents execute a strict pipeline when given a one-line spec:

  1. Plan — LLM decomposes the spec into ordered, implementable tasks
  2. Code — Each task is coded using the optimal model from the router
  3. Test — Real verification runs inside a sandboxed workspace (compileall, pytest, node --check)
  4. Fix — Failed tests feed back into the LLM for repair (up to 3 rounds)
  5. Review — Strict reviewer emits VERDICT: PASS or FIX
  6. Document — README.md and API docs auto-generated from final tree
  7. Package — Workspace compressed into a downloadable .tar.gz artifact

Launching an Autonomous Run

The SDLC service runs on :8050. Submit a spec and the agents handle the rest:

curl -X POST http://localhost:8050/auto/start \
  -H "Content-Type: application/json" \
  -d '{
    "spec": "Build a Python REST API using FastAPI with SQLite that handles user authentication",
    "profile": "balanced",
    "max_tasks": 8,
    "enable_shell": true
  }'

Track progress in the Active Runs tab or at /dashboard.

Custom Pipelines — Manual Agent Control

Don't want the full loop? Call individual agent personas via the Pipeline API on :8170:

# Scaffold from a spec
curl -X POST http://localhost:8170/pipeline/scaffold \
  -H "Content-Type: application/json" \
  -d '{"spec": "Build a CLI todo app", "profile": "creative"}'

# Refactor existing code
curl -X POST http://localhost:8170/pipeline/refactor \
  -H "Content-Type: application/json" \
  -d '{"code": "def add(a,b): return a+b", "language": "python",
       "goals": "add type hints", "profile": "strict"}'

# Debug an error
curl -X POST http://localhost:8170/pipeline/debug \
  -H "Content-Type: application/json" \
  -d '{"code": "x = 1/0", "error": "ZeroDivisionError", "language": "python"}'

# Build a custom multi-step pipeline
curl -X POST http://localhost:8170/pipeline/custom \
  -H "Content-Type: application/json" \
  -d '{
    "spec": "Build a FastAPI app",
    "steps": [
      {"phase": "scaffold", "input": {"spec": "Build a FastAPI app"}},
      {"phase": "refactor", "input": {"goals": "add error handling"}},
      {"phase": "document", "input": {}}
    ]
  }'

Available phases: scaffold, refactor, debug, analyze, review, document.
