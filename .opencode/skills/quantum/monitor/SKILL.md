# Quantum C2 Monitor Skill

Monitor system health and operational status.

## Commands

- `status` — Check overall system status
- `health` — Verify all services are running
- `resources` — Check CPU, memory, disk usage
- `logs` — View recent system logs
- `alerts` — Check for active alerts
