# Forensic Analysis

This skill provides the capability to perform deep-dive analysis on digital artifacts.

## Analysis Domains
- **Log Forensics**: Parsing Event Logs, Syslog, and custom C2 logs to reconstruct attacker/victim timelines.
- **Metadata Extraction**: Extracting EXIF, timestamps, and author data from exfiltrated documents.
- **Memory Analysis**: Analyzing RAM dumps for injected code, hidden processes, and encryption keys.

## Intelligence Extraction
- **Timeline Reconstruction**: Creating a master sequence of events (T0 $\rightarrow$ T-final).
- **Artifact Correlation**: Linking a specific file modification to a known C2 command.
- **Pattern Recognition**: Identifying the "digital fingerprint" of specific tools or operators.
