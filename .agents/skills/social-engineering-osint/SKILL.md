# Social Engineering & OSINT

This skill handles the "human element" of the attack chain.

## OSINT Workflows
- **Deep Profiling**: Automating the collection of data from social media, public records, and leaked databases.
- **Relationship Mapping**: Identifying key personnel and their connections to find the "weakest link."
- **Infrastructure Mapping**: Finding leaked API keys, forgotten dev servers, and exposed `.git` directories.

## Social Engineering (SE)
- **Pretexting**: Creating a believable persona and backstory for the target.
- **Phishing Generation**: Using AI to write highly personalized emails/messages based on OSINT profiles.
- **Payload Delivery**: coordinating with `pegasus-stealth-net` to deliver the payload via the social vector.
